# 旧链接与延迟 -1：分层实测

适用于“哪个还能用”“全部 -1”“超时”“能导入但打不开”。只检查用户本次给出的节点与明确授权文件；缺少 HY2 密码、指纹或完整 URI 时只询问缺失项，继续测试已有完整链接，不从旧管理文件或密码库补取。

## 1. 建立测试清单

在任务临时私密目录解析 URI，记录别名、协议、入口和**外部**端口。完整 URI 含凭据，不放进技能、公开日志或仓库。纠正粘贴带来的 scheme 反斜杠、明确的域名转义和首尾空白；不批量删掉密码中的反斜杠，不改写百分号编码内容。

同一实例出现多个历史配置时分别标记版本。外部映射只有在当次已有可靠记录时才纠正；无法确认时测试原链接并标注待核对。不能根据“端口看起来不对”猜一个新端口。

记录应用版本与实际测试核心版本；应用版本、服务端版本和客户端核心版本是三项。优先使用用户指定安装位置或安装包中的合适核心，缺失时从官方渠道获取兼容发行包并验证。不要搜索整个个人目录寻找配置。

## 2. 逐层定位

| 层次 | 可记录的证据 | 不能替代的后续检查 |
| --- | --- | --- |
| 配置/导入 | URI 可解析、所选核心配置校验通过、活动节点及分组正确 | 不证明远端存在 |
| TCP 传输 | 向该入口外部端口建立 TCP 连接 | 不证明 REALITY/VLESS 认证和代理成功 |
| HY2 传输与认证 | 真实 HY2/QUIC 握手；证书或认证错误可证明收到某层响应 | UDP 探针无报错、TCP 同端口成功都不算 HY2 可用 |
| 代理业务 | 经本次独立 SOCKS 请求 HTTPS，记录预期状态、退出码及总耗时 | 不证明吞吐、指定网站、出口国家或 IPPure |
| 用户客户端 | 最终 URI 在用户指定客户端实际导入并建立新连接 | 独立核心成功不能写成“已在 v2rayN 验证” |

TCP 可先做小批量并行探测，单次例如 5–10 秒；失败可有限复测一次。TCP 超时的结论写“当前测试网络到该入口/端口超时”。只有跨网络、服务端与协议证据支持时才判断封锁范围，不直接升级为“整个 IP 永久被封”。

## 3. 独立核心完成 HTTPS

VLESS 使用 [xray-config.md](xray-config.md) 的临时客户端模板；HY2 使用 [hy2-verification.md](hy2-verification.md) 的最终 URI 输入方式。只监听 `127.0.0.1` 的空闲临时端口，记录本次 PID；不启用 TUN，不更改系统代理，不覆盖用户客户端配置。

以最终待推荐 URI 为唯一参数来源，完成配置检查后启动核心。REALITY 核对 UUID、Flow、SNI、公钥、Short ID；HY2 核对认证、混淆、SNI 和固定指纹。记录配置报错和握手阶段，避免只看本地 SOCKS 已监听。

通过同一个 SOCKS 执行 HTTPS，使用 [hy2-verification.md](hy2-verification.md) 的结构化 curl 参数：`--disable` 为首项，`--noproxy` 传入独立空字符串，显式 `socks5h://127.0.0.1:<端口>`，设置连接与总超时，保存退出码/HTTP 状态/请求总耗时。不得以本机直连成功替代代理成功。[curl 官方手册](https://curl.se/docs/manpage.html)

默认小流量目标可为 `https://www.gstatic.com/generate_204`，预期 204。若握手成功而该站失败，再选一个说明预期响应的独立 HTTPS 目标，区分测试站异常、节点出站/DNS 和客户端问题；不绕过 HTTPS 证书验证。

若独立核心通过但 v2rayN 仍显示 -1，核对其测试地址、超时、活动节点、分组/路由、实际核心和新连接日志。已有配置先备份，原配置与干净导入作对比。用户没有要求操作现有客户端时给出准确导入步骤；不要自行全局重置路由或升级所有核心。

## 4. 可用性结论

每条节点输出测试时间、协议、传输结果、握手/应用结果、实际 HTTPS 结果和判定：

- **本次可用**：通过最终链接的独立代理 HTTPS 测试，推荐该条。
- **仅端口可达**：TCP 建连成功但代理测试未通过，不推荐为可用节点。
- **当前测试未连通**：超时或失败，附具体阶段和有限复测结果。
- **未测试/资料不足**：缺完整链接或必要参数，不能并入“全部失效”。

只推荐本次通过的链接；多条通过时按用户关心的指标排序。单次总耗时不是稳定速度排名。所有节点都失败就说明当前没有已验证可用项，继续在授权范围内诊断；没有完整新配置时不编造替代链接。

纯可用性检查不执行充值、重装、服务端改密或实例重启，也不主动检测测试机真实出口和个人地区。退出时停止本次准确 PID 对应的客户端，删除本次临时配置和凭据副本，保留必要的脱敏结果。后续获授权修复时再进入 recovery；重启自启属于另一个验收维度。
